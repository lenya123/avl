# AVL Tree

Самобалансирующееся дерево поиска на C++ — ассоциативный контейнер «ключ → значение» с поддержкой повторяющихся ключей и интерфейсом в стиле STL.

## Возможности

- `insert`, `erase`, `find` за O(log n): после каждой вставки и удаления узлы на пути балансируются малыми и большими поворотами
- двунаправленные `Iterator` и `ConstIterator`, обход в порядке возрастания ключей, `--end()`
- `equalRange` — все элементы с заданным ключом, `min` / `max`, в том числе по значению среди одинаковых ключей
- правило пяти: копирование и перемещение дерева

## Проверка

```bash
g++ -std=c++17 -O2 AVL.cpp test.cpp -o test && ./test
```

```
sorted insert 100000 keys: size=100000 height=17
erase even keys: size=50000 height=16
random test vs std::multimap (20000 ops): OK
```

Тест сверяет дерево со `std::multimap` на 20 000 случайных вставках и удалениях и проверяет, что высота не превышает теоретическую границу AVL (≈1.44·log₂n).
